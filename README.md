## Quick Tips

- **Break large tasks into small steps** — free models need more guidance
- **Write clear, specific instructions** — more details = better results
- **Use Rules** to standardize code style across the project
- **Create Skills** for repetitive tasks to save time
- **Try MCP** to connect external tools and expand agent capabilities
- **Monitor the Context Window** — avoid pollution for better performance
